# Live-Bottle-Counting
🧴 Smart Bottle Counting System

An AI-based bottle detection and visible bottle counting system using Python, YOLO, and OpenCV.

📌 Project Overview

The Smart Bottle Counting System detects bottles in conveyor belt videos using computer vision and deep learning. It processes video frames, identifies bottles, displays bounding boxes, and calculates the number of bottles visible in each frame.

The project is developed as an advanced BCA computer vision project.

🚀 Features

- Bottle detection using YOLO
- Video processing with OpenCV
- Visible bottle counting per frame
- Bounding box visualization
- CSV history export
- Excel report generation
- Bottle count analytics
- Google Colab support

🛠️ Technologies Used

- Python
- YOLO
- OpenCV
- Pandas
- NumPy
- Matplotlib
- Google Colab
- Excel

⚙️ How to Run

1. Open the Google Colab notebook.
2. Install the required libraries.
3. Upload a conveyor belt bottle video.
4. Load the YOLO model.
5. Run the bottle detection system.
6. View the annotated output video.
7. Export CSV and Excel history.

🎯 Project Objective

To develop an AI-based computer vision system that detects and counts bottles visible in video frames, providing a foundation for automated bottle monitoring and industrial analytics.
